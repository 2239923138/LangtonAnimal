# LangtonAnimal

把兰顿蚂蚁（Langton's Ant）和二维图灵蚂蚁（Turmite）搬进 Minecraft——用原版生物当载体，按整数方块网格严格步进，在超平坦世界的地面上"画"出元胞自动机的轨迹。

- **Minecraft** 1.21.1
- **NeoForge** 21.1.264+
- **Java** 21
- 客户端与服务端都需要安装

## 它是什么

每个"兰顿生物"都带着一套规则：

```
条件方块  ->  转向动作  +  目标替换方块
```

每一步：读取脚下方块 → 查表得到转向 → 改掉脚下方块 → 朝新方向走一格。经典的 RL 规则跑上一万步，就会自己修出一条"高速公路"。

规则的条件与目标可以是 16 色羊毛 / 16 色混凝土 / 16 色陶瓦（共 48 种），也可以引用"默认初始方块"这个动态标识符——外层把默认方块从草方块改成石头，所有引用它的规则会自动跟着变。

## 安装

1. 装好 Minecraft 1.21.1 + NeoForge 21.1.264 或更高。
2. 把 `langtonanimal-<version>+mc1.21.1.jar` 放进 `mods/`。
3. 启动游戏，客户端与服务端都要装。

## 快速上手

> [!IMPORTANT]
>
> 请使用超平坦世界!

```mcfunction
# 在配置界面（默认按 L）里新建一个预设，或者直接用命令
/langtona summon RL蚂蚁 ant_01 north 5
/langtona start ant_01
```

生物出场时默认**停止**、朝**北**、速度 **1 步/秒**。跑起来后脚下会留下染色方块的轨迹。

手持**烈焰棒**时，生物头顶会显示 `生物名 [预设名]`，预设名用该预设的颜色；不拿烈焰棒则完全不显示名字。烈焰棒同时也是操作手柄：

| 操作 | 作用 |
| :--- | :--- |
| `Ctrl` + 滚轮 | 切换模式：0 选择 / 1 编辑 / 2 启停 / 3 调速 |
| `Alt` + 滚轮 | 切换范围：单个生物 / 同预设 / 全体 |
| 右键生物 | 选择目标；编辑模式下打开预设窗口 |
| 右键空气 | 仅启停模式：按当前目标的下一个状态整体启停 |
| `Shift` + 滚轮 | 仅调速模式：加速 / 减速 |
| 右下角 HUD | 实时显示全部模式与范围，高亮当前项 |

选择模式会把作用范围内的生物用线框标出来：单个和同预设用预设颜色，全体用白色。

编辑模式对普通生物同样可用——选一个预设，它会被就地转化成兰顿生物（自动加 NoAI、静音、无敌、禁刷没）。

## 命令

主命令 `/langtonanimal`，简写 `/langtona`，需要 OP。

| 命令 | 说明 |
| :--- | :--- |
| `/langtona summon <预设> <生物名> [朝向] [速度]` | 召唤一只，自动落到下方最近的可站立地面；朝向 north/south/east/west，速度单位为步/秒 |
| `/langtona start <名称>` | 启动；名称可以是生物名、预设名或 `all` |
| `/langtona stop <名称>` | 停止；同上 |
| `/langtona speed <名称> <步/秒>` | 设置速度，1 ~ 1280；同上 |
| `/langtona remove <名称>` | 移除生物并释放名字；同上 |
| `/langtona restore <名称>` | 把地面复原到被改动前的状态；同上 |
| `/langtona list` | 列出全部生物：预设、状态、速度、坐标、区块是否加载 |

速度是**每秒步数**，不是每步多少 tick。引擎每 tick 按 `速度 / 20` 累加，所以 200 步/秒就是单 tick 走 10 步；硬上限 64 步/tick。

## 预设与配置

预设保存在 `config/langtonanimal/presets.json`，跨存档通用，由服务端写入。图形界面里能做的事：

- 顶层默认初始方块（留空按草方块处理）
- 预设列表：名称、载体生物、规则条数，带颜色条；每项可编辑、复制（名字自动加后缀）、删除（带确认）
- 预设编辑：名称、颜色（16 色）、载体生物、规则行（条件 / 动作 / 目标）
- 方块选择：按羊毛 / 混凝土 / 陶瓦分类，点击即选

保存时会被校验，不通过直接拦下：

- 预设名非空、不含空格、不与其它预设或在场生物重名，不能叫 `all`
- 载体生物合法（排除末影龙与凋灵）
- 条件不重复（解析默认方块标识符后再比较）
- 必须包含针对当前默认初始方块的规则，否则第一步就迈不出去
- 闭环检查：任何规则生成的目标方块，都必须有对应的条件规则

## 回退

`/langtona restore` 依赖一张改动历史表：某个坐标第一次被规则方块覆盖之前，原始方块会被记录下来，之后再经过同一格不会覆盖记录。因此：

- 复原按"首次触碰"的原始状态写回，不是撤销最后一步
- `/langtona restore all` 会复原整张表，包括已经移除的生物留下的痕迹
- **会覆盖你后来在同一位置放的方块**
- 记录上限 20 万格，超出后不再记录新坐标

## 从源码构建

```bash
git clone git@github.com:2239923138/LangtonAnimal.git
cd LangtonAnimal
./gradlew build
```

产物在 `build/libs/`。

需要 JDK 21（`JAVA_HOME` 指向它）。Gradle 9 不支持用 Java 26 运行，别用系统最新的 JDK 直接跑。

开发环境另有 `./gradlew runClient` / `runServer`，首次运行需要能访问 `maven.neoforged.net`。

## 已知限制

- 所有命令与烈焰棒操作除单人存档外都要求 OP 权限
- 全体范围的高亮统一用白色，不按预设区分
- 载体必须是生物实体；飞行、水生生物同样需要脚下有实心方块才能移动（与设计一致）
- 地形复原是无条件写回，玩家后续的建筑会被覆盖
